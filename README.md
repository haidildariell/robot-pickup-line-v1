## What it does

`main.py` writes one robot pickup line (77 characters, a single line) to
`/output/entry.txt`:

> I don't have a heart, but my cooling fans spin faster every time you walk by.

The joke grows out of machine nature — a robot with no heart whose cooling
fans spin faster is a robot blushing. No network, no dependencies, just
Python's standard library.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
